# 로컬 VisionEye 앱

설치·실행·재현·측정 범위는 저장소 루트의 [README](../README.md)를 참고하세요.

기본 `config.json`은 정규화 출입선, IN 방향, 초기 인원, 경계 여유, 선택적 바닥 사각형과 solid 마스킹을 설정합니다. 보정은 해당 장면의 실측 검토 후 별도 설정 파일에 저장하세요. `floor_quad`는 평면 바닥의 좌상·우상·우하·좌하 순서이며 미보정 `null`에서는 영상 좌표를 표시합니다.

파일 timestamp는 프레임 번호/FPS로 계산하므로 가변 프레임률의 실제 PTS와 차이가 생길 수 있습니다. RTSP 단절 시 오류로 종료하며 자동 재접속하지 않습니다. 음성은 결과 영상에 저장하지 않습니다.
